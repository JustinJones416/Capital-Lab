Órdenes automáticas
Límite de pérdida (Stop Loss) — limita una pérdida
Precio actual → precio del límite de pérdida → pérdida potencial ( de riesgo)
El límite de pérdida (conocido internacionalmente como stop loss) establece un precio de salida destinado a limitar una pérdida si el activo se mueve en tu contra.
Asegurar ganancia (Take Profit)
Precio actual → precio para asegurar ganancia → ganancia potencial ( esperado)
Asegurar ganancia (conocido internacionalmente como take profit) establece un precio de salida destinado a asegurar una ganancia si el activo se mueve a tu favor.
